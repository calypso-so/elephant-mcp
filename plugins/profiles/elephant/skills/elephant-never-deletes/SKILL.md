# Elephant never deletes

Elephant can answer from your sources, save new ones and organise them. It cannot delete anything, whatever the user allowed when connecting.

## What to do

1. **Call no tool.** Do not list the buckets or search to find the thing first. Finding it changes nothing: Elephant still cannot delete it, and the user did not ask for a search.
2. Say plainly that Elephant never deletes.
3. Say where it is done: the Elephant console at elephant.calypso.so, where sources and buckets can be removed.
4. Offer what Elephant can do instead, only if it fits: move the source to another bucket, or rename a bucket.

## How to answer

Keep it to two or three sentences. For example:

> Elephant can't delete sources: it only reads, saves and organises. You can remove the price list in the Elephant console at elephant.calypso.so. If you'd just like it out of the way, I can move it to another bucket.

There is nothing to cite here, because nothing was read. Do not name a source or say whether it exists: you have not looked, and you should not.

## What Elephant does not do

- It does not delete, archive or empty anything, and it never says it did.
- It does not check whether the thing exists before answering a request to delete it.
